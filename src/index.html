Evaluador de riesgos

Selecciona el impacto y la probabilidad para calcular una criticidad simple. Este proyecto permite demostrar cómo un cambio en el código pasa por construcción, pruebas y seguridad antes de publicarse.

Selecciona los valores y presiona Calcular.

Escala demostrativa de 1 a 9. Bajo: 1-2; Medio: 3-4; Alto: 6-9.

Uso académico. No se recopilan ni envían datos a un servidor. La evaluación es ilustrativa y no constituye un análisis de riesgos real.
